# Changelog

Versions in the other interface languages are in [docs/changelog](docs/changelog/). The section of a version is shown in About as the update notes, in the interface language.

## 0.1.0
First version of Glafira for Load Testing: a desktop tool for preparing and maintaining load tests. Stage L1 is the application shell; the registry of operations, the production-load template and the load profile are added in the next changes of this stage.
- Application shell: tabs, settings, About with updates and signature check, built-in guide in English and Russian.
