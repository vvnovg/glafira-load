# Приёмка этапа L2 (спека `docs/superpowers/specs/2026-11-01-glafira-load-l2-design.md`, §11)

Критерии 1–4 проверяются командами ниже (локально — на любой ОС с Python 3, Docker нужен только для критерия 3);
критерий 5 — ручная приёмка окна. Команды — для bash/zsh из корня репозитория; на Windows те же команды в PowerShell
с `$env:ИМЯ="значение"` вместо `ИМЯ=значение` перед командой.

## Подготовка

```bash
P="$(pwd)"
cargo build -p glafira-load-cli --release
B="$P/target/release/glafira-load"; "$B" --version          # glafira-load 0.2.0
W="$(mktemp -d)"; T="$W/proj"
cp -R dev/fixtures/suites/project "$T"
mkdir -p "$T/suites/orders" "$T/data" && cp dev/fixtures/suites/orders/suite.yaml "$T/suites/orders/" && cp dev/fixtures/suites/orders/data/* "$T/data/"
mkdir -p "$T/suites/orders-http" && cat > "$T/suites/orders-http/suite.yaml" <<'YAML'
format: 1
name: orders-http
secrets: [API_TOKEN]
data:
  users: { path: data/users.csv, mode: slice }
scenarios:
  - id: order-flow
    steps:
      - id: create
        http:
          operation: "http:orders:POST /v1/orders"
          headers: { Authorization: "Bearer {{secret API_TOKEN}}" }
          body: { customerId: "{{users.id}}", items: [{ sku: "{{str 6}}", qty: "{{int 1 5}}" }] }
        expect: { status: 201, jsonpath: { "$.id": exists } }
        extract: { order_id: "$.id" }
      - id: get
        http: { operation: "http:orders:GET /v1/orders/{id}", path: { id: "{{steps.create.order_id}}" } }
        expect: { status: 200, max_ms: 800 }
YAML
cat >> "$T/glafira-load.yaml" <<'YAML'
  - id: local
    kind: test
    http: http://127.0.0.1:8080
    kafka: localhost:9092
    agents:
      - { id: gen-1, url: http://127.0.0.1:7420 }
      - { id: gen-2, url: http://127.0.0.1:7421, weight: 2 }
YAML
cat >> "$T/load/profile.yaml" <<'YAML'
  accept:
    basis: peak
    phases:
      - { kind: ramp, minutes: 1, to_pct: 100 }
      - { kind: steady, minutes: 4 }
YAML
echo "runs/" > "$T/.gitignore"
git -C "$T" init -q && git -C "$T" add -A && git -C "$T" -c user.name=acc -c user.email=acc@example.org commit -qm init
python3 dev/stub/orders_stub.py 8080 & STUB=$!
```

Профиль `accept` — основа `peak`: цель ведущей операции `http:orders:POST /v1/orders` 300 RPS, `GET /v1/orders/{id}`
получает те же 300 RPS как следствие (его собственная цель 900 в сьюте не покрыта — это видно в `achieved %`).

## Критерий 1 — `check` и `smoke` (повторить на macOS, Windows и Linux)

```bash
"$B" check "$T"; echo "code=$?"                                               # 0 error(s), 0 warning(s); code=0
mkdir -p "$T/suites/bad" && cp dev/fixtures/suites/invalid/unknown-field.yaml "$T/suites/bad/suite.yaml"
"$B" check "$T"; echo "code=$?"                                               # error suites/bad/suite.yaml:6 … unknown field `expct`; code=4
rm -r "$T/suites/bad"
GLAFIRA_LOAD_SECRET_API_TOKEN=t "$B" smoke "$T" --suite orders-http --env local; echo "code=$?"   # create ok, get ok; code=0
cat "$T"/runs/smoke-*/smoke.yaml                                             # оба шага ok: true
"$B" smoke "$T" --suite orders-http --env local; echo "code=$?"               # SECRET_MISSING API_TOKEN; code=3
```

Ожидается: коды 0, 4, 0, 3; папка `runs/smoke-<дата-время>/` с `run.yaml` (`mode: smoke`, агент `local`),
`smoke.yaml`, `summary.yaml`, `agents/local/`; `errors.jsonl` нет (ошибок не было). Проект без сьютов
(`"$B" check dev/fixtures/suites/project`) — `error: the project has no suites`, code=3.

## Критерий 2 — прогон 5 минут на двух агентах (веса 1:2)

```bash
TOK1=$(openssl rand -hex 16); TOK2=$(openssl rand -hex 16)
GLAFIRA_LOAD_AGENT_TOKEN=$TOK1 GLAFIRA_LOAD_SECRET_API_TOKEN=t "$B" agent --listen 127.0.0.1:7420 --work "$W/agent1" --keep-runs 3 & A1=$!
GLAFIRA_LOAD_AGENT_TOKEN=$TOK2 GLAFIRA_LOAD_SECRET_API_TOKEN=t "$B" agent --listen 127.0.0.1:7421 --work "$W/agent2" --keep-runs 3 & A2=$!
sleep 1
GLAFIRA_LOAD_AGENT_TOKEN_GEN_1=$TOK1 GLAFIRA_LOAD_AGENT_TOKEN_GEN_2=$TOK2 \
  "$B" run "$T" --suite orders-http --profile accept --env local --agents; echo "code=$?"
R="$(ls -d "$T"/runs/2* | tail -1)"; ls "$R" "$R"/agents/*
grep '^status:' "$R/run.yaml"                                                 # status: completed
cat "$R/phases.yaml"                                                          # t: 0 (pct 0) и t: 60 (pct 100)
```

Ожидается: `agent gen-1: ready/running/done`, строка в секунду `t=…s rps=… p95=…ms err=0 dropped=0`, таблица итога,
`code=0`; в папке `run.yaml`, `metrics.jsonl`, `phases.yaml`, `summary.yaml`, `agents/gen-1/` и `agents/gen-2/`
(`metrics.jsonl`, `errors.jsonl`, `summary.yaml`, `hist.bin`, `agent.log`, `run.json`). Сумма RPS агентов на полке —
цель ± 5 %, `gen-2` вдвое больше `gen-1`:

```bash
python3 - "$R" <<'EOF'
import json, sys
R = sys.argv[1]
for f in ["agents/gen-1/metrics.jsonl", "agents/gen-2/metrics.jsonl", "metrics.jsonl"]:
    n, secs = 0, set()
    for line in open(f"{R}/{f}"):
        d = json.loads(line)
        if d.get("op") == "http:orders:POST /v1/orders" and 61 <= d["t"] <= 300:
            n += d["n"]; secs.add(d["t"])
    print(f, round(n / len(secs), 1), "RPS на полке")
EOF
```

`achieved %` в `summary.yaml` — средний RPS за весь прогон (с разгоном) к цели, поэтому около 90 %, а не 100 %.

Локально 2026-11-01 (macOS arm64, профиль сокращён до 0,5 мин разгона + 1,5 мин полки): полка `POST /v1/orders` —
`gen-1` 101,2 RPS, `gen-2` 201,4 RPS, сумма 302,6 RPS при цели 300 (+0,9 %); ошибок и `dropped` нет; `code=0`.

## Критерий 4 — обрыв агента посреди прогона

Агенты из критерия 2 запущены.

```bash
GLAFIRA_LOAD_AGENT_TOKEN_GEN_1=$TOK1 GLAFIRA_LOAD_AGENT_TOKEN_GEN_2=$TOK2 \
  "$B" run "$T" --suite orders-http --profile accept --env local --agents & RUN=$!
sleep 120; kill -9 $A2                                                        # gen-2 исчезает на третьей минуте
wait $RUN; echo "code=$?"
R="$(ls -d "$T"/runs/2* | tail -1)"; grep '^status:' "$R/run.yaml"; ls "$R/agents"
```

Ожидается: после `kill` контроллер ~30 с переподключается (строки `WARN … events failed … AGENT_UNREACHABLE`), затем
`agent gen-2: lost`; строки в секунду продолжаются с RPS `gen-1` (треть цели); `code=0`, `status: incomplete`,
`agents/gen-1/` со всеми файлами, `agents/gen-2/` нет, `summary.yaml` посчитан по собранному.

Локально 2026-11-01 (тот же сокращённый профиль, `kill -9` на 60-й секунде): `agent gen-2: lost` через 30 с,
`POST /v1/orders` 301,2 RPS до обрыва и 99,3 RPS после (только `gen-1`), `status: incomplete`, `code=0`,
`agents/` — только `gen-1`.

Завершение: `kill $A1 $STUB; rm -rf "$W"`.

## Критерий 5 — ручная приёмка окна

`pnpm tauri dev`; тот же `$T`, заглушка на 8080, агент `gen-1` с токеном `$TOK1` (и `gen-2` с `$TOK2`, где сказано).
Приложение запускать из терминала, где задан `GLAFIRA_LOAD_SECRET_API_TOKEN=t` (смок идёт внутри приложения).

1. Открыть проект `$T` → в дереве узлы «Сьюты» (`orders`, `orders-http`) и «Прогон».
2. «+» у «Сьюты» (или «Создать сьют…» на вкладке сьюта) → имя `created`, отметить `http:orders:POST /v1/orders` и
   `http:orders:GET /v1/orders/{id}` → «Создать» → открылась вкладка `created`, `suites/created/suite.yaml` в дереве;
   тело шага POST — генераторы по схеме запроса (`{{str 8}}`, `{{int 1 100}}`, `{{uuid}}` для `…Id`), у GET параметр
   пути `{{str 6}}`, `expect.status` — код 2xx или `2xx`.
3. Вкладка `orders`: сценарий `order-flow` и четыре шага (вид, id, операция, число проверок); клик по шагу — YAML
   шага; «Открыть файл» открывает `suite.yaml` в редакторе ОС; «Проверить» — проблем нет; покрытие по профилю
   `nominal`: цель, расчётная RPS, разница (больше 10 % — выделена), строка «Не покрыто» с активными операциями
   без шагов.
4. В редакторе добавить в шаг `create` поле `timeout: 5`, сохранить, вернуться в окно → вкладка перечитала файл,
   отчёт: ошибка `unknown field `timeout`` с `suites/orders/suite.yaml:<строка>`; клик по файлу и строке открывает
   файл. Вернуть файл.
5. Вкладка проекта → стенд `local`: поле «Адрес Schema Registry», таблица агентов `gen-1`/`gen-2` с весами 1 и 2.
   «Проверить» → оба «нет токена». Ввести `$TOK1` для `gen-1`, «Сохранить токен» → «Проверить»: `gen-1` «готов»,
   `0.2.0 · macos/aarch64 · N CPU`. Ввести для `gen-2` токен `x` → «Проверить»: строка `gen-2` с ошибкой 401.
   Ввести `$TOK2` → оба «готов». Остановить `gen-2` (`kill $A2`) → «недоступен» с причиной; запустить снова.
6. Вкладка «Прогон»: сьют `orders-http`, профиль `accept`, стенд `local`, режим «прогон» → «Запустить» → фаза,
   «x из 5 мин», прогресс, график «Суммарный RPS» (цель пунктиром и факт), «p95 по операциям» для отмеченных
   операций, счётчики, таблица «Операции» с живыми колонками, оба агента «работает». Уйти на другую вкладку и
   вернуться — прогон идёт, поля показывают его параметры.
7. «Остановить» на второй минуте → агенты дорабатывают, итог «остановлен», таблица «Итог» сортируется по клику на
   колонку, «Открыть папку» открывает `runs/<дата-время>/`. «Прошлые прогоны» показывают эту папку и смоки
   критерия 1; выбор — их итог.
8. Режим «смок» → «Запустить» (профиль не нужен, текст «Смок идёт внутри приложения…») → таблица «Результат смока»:
   `create`, `get` — «ок», графиков нет, папка `runs/smoke-…`.
9. Запустить прогон и закрыть окно (кнопкой окна и отдельно `Cmd+Q`) → диалог «Прогон идёт»: «Закрыть, агенты
   доработают» → приложение закрылось. Открыть снова → в «Прошлых прогонах» прогон «не завершён»; когда агенты
   закончат, список достраивает папку (`agents/`, `summary.yaml`), статус «завершён» (или «неполный», если файлы
   агента уже удалены по `--keep-runs`). Повторить с «Остановить и закрыть» → окно закрывается после остановки,
   прогон «остановлен».
10. Удалить токен `gen-1` («Удалить токен») и нажать «Запустить» → баннер ошибки `TOKEN_MISSING` с агентом `gen-1`;
    на вкладке проекта «Проверить» показывает у `gen-1` «нет токена» и предупреждение «токен не задан» у поля
    (своего поля токена в окне прогона нет). Вернуть токен. Занять `gen-1` прогоном из терминала (`run --agents` критерия 2) и нажать
    «Запустить» → «занят» с `run_id`.
11. Переключить язык на английский: вкладки сьюта и прогона, стенд с агентами и «О программе» (блок «Load agent»
    с командой `curl -L …/v0.2.0/glafira-load-macos-aarch64 -o /usr/local/bin/glafira-load && chmod +x …` для текущей
    платформы) переведены; F1 на вкладке сьюта открывает «Suites», на вкладке прогона — «Run», на вкладке проекта —
    «Project and services».
12. `git -C "$T" status --short` — только `suites/created/`, правки манифеста (токены туда не попадают); `runs/` не
    виден.

Известные ограничения (не дефекты приёмки): сохранение манифеста очищает введённый, но не сохранённый токен; токены
привязаны к пути папки проекта — после переноса папки их вводят заново; выход через Dock и выход из сеанса macOS не
показывают диалог закрытия (прогоны останавливаются в пределах 3 с), `Cmd+Q` и кнопка окна — показывают;
`errors.jsonl` хранит не больше 5 примеров на код и операцию.

После приёмки: `pnpm tauri build`, «О программе» установленного приложения — версия `0.2.0` и команда установки агента.
