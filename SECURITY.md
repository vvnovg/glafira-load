# Security policy

## Supported versions

Only the latest release on https://github.com/vvnovg/glafira-load-releases/releases receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting: on the repository page open
the **Security** tab and click **Report a vulnerability**. Describe the problem, the app version and the steps
to reproduce it.

You will get a reply within 7 days. When a fix is released, the report is published as a security advisory with
credit to the reporter, unless you ask otherwise.

## What matters most

Glafira for Load Testing works with local project folders and Git repositories of load tests. Reports about path
handling (access outside the project folder or the clone), launching external programs such as `git`, parsing of files
from untrusted repositories, and the administrator policy are especially welcome.
