# Начало работы

Glafira for Load Testing — настольный инструмент подготовки и сопровождения нагрузочного тестирования. Эта версия
(этап L1) строит реестр операций по контрактам сервисов, выгружает шаблон нагрузки ПРОМ в Excel, импортирует
заполненный шаблон и считает профиль нагрузки. CLI-раннер, сьюты, моки и отчёты появятся в следующих этапах.

Всё, что делает Glafira, хранится в папке проекта обычными YAML-файлами, которые вы коммитите в git рядом с тестами.
Клоны сервисов приложение читает, но никогда не меняет. По сети оно ничего не отправляет, кроме проверки обновлений,
а её организация может выключить политикой.

## Установка {#install}

Установщики для macOS (`.dmg`), Windows (`.msi`) и Linux (`.deb`, `.rpm`, `.AppImage`) публикуются на
https://github.com/vvnovg/glafira-load-releases/releases. Организация может настроить приложение политикой:
тогда часть настроек задаёт администратор.

## Первый проект {#first-project}

Проект НТ — папка в git: манифест `glafira-load.yaml`, реестр операций, цифры нагрузки ПРОМ и профиль нагрузки.
Тестируемые сервисы — локальные клоны git где-то на вашем диске.

1. Нажмите [[ui:sidebar.newProject]] в левой панели.
2. Введите [[ui:project.name]], нажмите [[ui:project.chooseFolder]] и выберите пустую папку внутри вашего
   git-репозитория, затем нажмите [[ui:project.create]]. Проект появится в левой панели в разделе [[ui:sidebar.projects]].
3. На вкладке проекта нажмите [[ui:project.addService]], введите [[ui:project.serviceId]] (строчные латинские буквы,
   цифры и дефис) и выберите папку клона сервиса. Нажмите [[ui:common.save]].
4. Откройте сервис в левой панели в разделе [[ui:sidebar.services]]. Glafira покажет найденные в клоне контракты.
   Нажмите [[ui:service.scan]].
5. Откройте [[ui:sidebar.registry]]: в нём операции сервиса со схемами запроса и ответа.

Существующий проект открывается кнопкой [[ui:sidebar.openProject]]. Дальше — выгрузить шаблон нагрузки ПРОМ
([Нагрузка ПРОМ](prod-load.md)) и посчитать профиль ([Профиль нагрузки](profile.md)). Подробнее о папке проекта —
[Проект и сервисы](project.md).

## Язык интерфейса {#language}

Откройте [[ui:sidebar.settings]] и выберите [[ui:settings.language.label]]. По умолчанию — как в системе. Если язык
задан вашей организацией, выбор недоступен.

## Справка {#help}

Клавиша F1 на любом экране открывает главу руководства о нём. Руководство работает без интернета; поиск — в поле над
содержанием. У многих полей есть подсказка «?».
