# Профиль нагрузки

Профиль нагрузки превращает цифры ПРОМ в цели для тестового стенда: сколько запросов в секунду получает каждая
операция и как нагрузка меняется во времени. Он хранится в `load/profile.yaml`; раннер следующего этапа исполняет его
как есть. Вкладка открывается пунктом [[ui:sidebar.profile]] в левой панели.

## Коэффициенты {#coefficients}

Цель операции считается так:

```
цель RPS = цифра ПРОМ × k_env × k_growth
```

- `k_env` — мощность тестового стенда относительно ПРОМ: `0.5` для стенда вдвое меньше;
- `k_growth` — запас роста: `1.3`, чтобы проверить нагрузку на 30 % выше сегодняшней.

По умолчанию оба равны `1` и не могут быть отрицательными. Задайте их в разделе [[ui:profile.coefficients]]. Если
сервису или операции нужны другие значения, добавьте строку в [[ui:profile.serviceOverrides]] (по ID сервиса) или
[[ui:profile.operationOverrides]] (по ID операции) и заполните только отличающийся коэффициент. Переопределение операции
сильнее сервисного, сервисное — общего значения.

Изменения хранятся черновиком, пока вы не нажмёте [[ui:common.save]]; [[ui:project.revert]] возвращает сохранённый файл.

## Профили и фазы {#phases}

В проекте несколько именованных профилей. У нового проекта их три:

| Профиль | Основа | Фазы |
|---|---|---|
| `nominal` | среднее | разгон до 100 % за 10 мин, полка 60 мин, спад до 0 % за 5 мин |
| `peak` | пик | разгон до 100 % за 5 мин, полка 30 мин |
| `stress` | пик | ступени по 25 % по 10 мин, до 300 % |

Профили добавляются, переименовываются и удаляются в разделе [[ui:profile.profiles]]. [[ui:profile.basis]] выбирает,
какая цифра ПРОМ — это 100 %: [[ui:profile.basisAvg]] или [[ui:profile.basisPeak]]. Профиль — список фаз, которые идут
одна за другой:

- **разгон** — линейно от текущего уровня до заданного процента за заданное число минут;
- **полка** — держит текущий уровень заданное число минут;
- **ступени** — растёт ступенями: одна ступень, две и так далее до максимума, каждая держится заданное число минут.

Фазы добавляются кнопкой [[ui:profile.addPhase]] и переставляются кнопками [[ui:profile.moveUp]] и
[[ui:profile.moveDown]].

## Цели и доли {#targets}

После сохранения на вкладке видны цели выбранного профиля: для каждой операции с цифрами ПРОМ — основа, действующие
коэффициенты, цель RPS и её доля от суммы. В заголовке — суммарный RPS и длительность профиля. Цели считаются по
сохранённому файлу; пока есть несохранённые изменения, вкладка об этом сообщает.

Активные операции без цифр ПРОМ перечислены в списке «не покрыто»: нагрузки на них не будет, пока вы не импортируете их
цифры ([Нагрузка ПРОМ](prod-load.md)). Удалённые операции не участвуют.

## График {#chart}

График показывает профиль во времени: минуты по горизонтали, процент от цели на левой оси и суммарный RPS на правой.
Вертикальные линии отмечают начало каждой фазы.

## Файл load/profile.yaml {#file}

```yaml
format: 1
coefficients:
  k_env: 0.5
  k_growth: 1.3
  overrides:
    services:
      billing: { k_env: 0.3 }
    operations:
      "http:orders:POST /v1/orders": { k_growth: 2.0 }
profiles:
  nominal:
    basis: avg
    phases:
      - { kind: ramp, minutes: 10, to_pct: 100 }
      - { kind: steady, minutes: 60 }
      - { kind: ramp, minutes: 5, to_pct: 0 }
  stress:
    basis: peak
    phases:
      - { kind: steps, step_pct: 25, step_minutes: 10, max_pct: 300 }
```

Файл рассчитан на чтение в `git diff` и правится вручную; изменения видны на вкладке, когда вы откроете её заново.
