# Обновления

В этой главе — как обновить приложение, экран [[ui:sidebar.about]] и как поддержать проект.

## Обновления {#updates}

Обновления изнутри приложения появятся в следующих версиях: установщики этой версии ещё не подписаны для
автообновления. До тех пор скачивайте новые версии со страницы релизов и устанавливайте поверх старой:
https://github.com/vvnovg/glafira-load-releases/releases

Проекты остаются в своих папках, а настройки приложения при установке новой версии сохраняются.

Раздел [[ui:about.updates.title]] на экране [[ui:sidebar.about]] уже есть. В этой версии [[ui:about.updates.check]]
отвечает «[[ui:errors.updates.notConfigured]]», и приложение не обращается к серверу обновлений. Когда обновления
включатся, приложение будет проверять их один раз при запуске и показывать над вкладками уведомление о новой версии.

Организация может выключить проверку обновлений политикой `updatesEnabled` или направить её на внутреннее зеркало
политикой `updateUrl`. Когда проверка выключена, [[ui:about.updates.check]] отвечает «[[ui:errors.updates.managed]]», а
приложение никогда не обращается к серверу обновлений.

## О программе {#about}

Откройте [[ui:sidebar.about]] внизу левой панели. На экране — краткое описание приложения и строки:

- [[ui:about.version]] — номер версии, и [[ui:about.build]] — идентификатор исходного кода, из которого собрано приложение. Указывайте оба значения в обращении.
- [[ui:about.system]] — операционная система и архитектура процессора.
- [[ui:about.license]] — Apache 2.0; ссылка открывает текст лицензии в браузере.
- [[ui:about.policy]] — «[[ui:about.policySet]]» или «[[ui:about.policyNone]]». Ошибки политики перечислены ниже.
- [[ui:about.dataDir]] — папка с настройками приложения.
- [[ui:about.logDir]] — папка с файлами логов.

Раздел [[ui:about.agent.title]] показывает команду, которая скачивает агента нагрузки для операционной системы и
процессора этой машины ([Установка агента](agents.md#install)). Здесь же — раздел [[ui:about.updates.title]].

## Поддержать проект {#support}

Glafira for Load Testing бесплатна, её исходный код открыт под Apache License 2.0. Проект живёт на пожертвования. Пункт [[ui:support.title]] внизу левой панели и на экране [[ui:sidebar.about]] открывает страницу поддержки в браузере: https://github.com/vvnovg/glafira-load-releases/blob/main/SUPPORT.md
