# Список изменений

Русская версия [CHANGELOG.md](../../CHANGELOG.md). Раздел версии показывается в «О программе» как заметки к обновлению.

## 0.1.0
Выпущена 2026-10-31. Этап L1 «Каркас и реестр операций» Glafira for Load Testing — настольного инструмента подготовки и сопровождения нагрузочного тестирования.
- Проект НТ — папка в git: манифест `glafira-load.yaml`, сервисы из локальных клонов git с версией из `git describe`, стенды без паролей.
- Импортёры контрактов: OpenAPI 3.0/3.1 и Swagger 2.0, Protobuf, AsyncAPI 2 и 3, Avro и JSON Schema, миграции Flyway и Liquibase, аннотации Spring на Java и Kotlin. Контракты находятся в клоне автоматически.
- Реестр операций со слиянием при повторном разборе (новые, изменённые, удалённые, вернувшиеся; ручные поля сохраняются), снимками разборов и диффом между любыми двумя; ручные операции, в том числе SQL.
- Excel-шаблон нагрузки ПРОМ с защищёнными ID; импорт с предпросмотром заполненных, пустых, неизвестных и ошибочных строк и диффом до записи `load/prod-load.yaml`.
- Профиль нагрузки: коэффициенты с переопределениями по сервисам и операциям, профили из фаз разгона, полки и ступеней, цели и доли, непокрытые операции, график фаз.
- Языки: английский, русский. Встроенное руководство (F1). Политика администратора: `updatesEnabled`, `updateUrl`, `language`.
