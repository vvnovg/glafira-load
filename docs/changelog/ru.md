# Список изменений

Русская версия [CHANGELOG.md](../../CHANGELOG.md). Раздел версии показывается в «О программе» как заметки к обновлению.

## 0.1.0
Первая версия Glafira for Load Testing — настольного инструмента подготовки и сопровождения нагрузочного тестирования. Этап L1 — оболочка приложения; реестр операций, шаблон нагрузки ПРОМ и профиль нагрузки добавляются в следующих изменениях этапа.
- Оболочка приложения: вкладки, настройки, «О программе» с обновлениями и проверкой подписи, встроенное руководство на английском и русском.
