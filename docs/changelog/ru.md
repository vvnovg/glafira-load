# Список изменений

Русская версия [CHANGELOG.md](../../CHANGELOG.md). Раздел версии показывается в «О программе» как заметки к обновлению.

## 0.2.0
Выпущена 2026-11-xx (заменить датой релиза при простановке тега). Этап L2 «Сьют, агенты и прогон»: сьюты нагрузки, CLI `glafira-load` с агентами на машинах нагрузки и окно прогона.
- Сьют `suites/<имя>/suite.yaml`: сценарии из шагов HTTP, `kafka_produce` и `kafka_consume`, привязанных к операциям реестра, проверки `expect` (статус, JSONPath, схема ответа, `max_ms`), `extract` между шагами, файлы данных (CSV, JSON Lines) и выражения `{{…}}`; неизвестные поля — ошибка.
- Вкладка «Сьют»: сценарии и шаги деревом, `check` с файлом и строкой, покрытие профиля по операциям и «не покрыто», создание сьюта из операций реестра с телами по схемам запросов.
- CLI `glafira-load`: `check` (без сети), `smoke` (каждый сценарий один раз, со списком сломанных шагов), `run` (в своём процессе или на агентах стенда с `--agents`), `agent` (HTTP API с bearer-токеном и метриками по SSE). Коды возврата: 0 завершено, 2 остановлено, 3 ошибка запуска, 4 `check` или `smoke` нашли ошибки. Бинарники для Linux x86_64 и arm64 (статические), macOS arm64 и x86_64, Windows x64.
- Движок нагрузки: открытый цикл по RPS с пуассоновскими или ровными интервалами, `max_in_flight` с `dropped`, HTTP/1.1 и HTTP/2 через rustls, продюсер и потребитель Kafka с лагом, Avro через Schema Registry, гистограммы HDR, слитые по агентам; примеры ошибок с замаскированными секретами.
- Агенты в стенде манифеста с весами; токены в хранилище ОС; секреты стенда — только переменные `GLAFIRA_LOAD_SECRET_<ИМЯ>` на агентах. Стенд без агентов исполняет нагрузку внутри приложения.
- Вкладка «Прогон»: сьют, профиль, стенд, `run` или `smoke`, статус агентов, живые графики RPS и p95, счётчики, таблица операций, остановка, итог, прошлые прогоны; закрытие окна во время прогона спрашивает, остановить его или оставить агентам. Результаты — в `runs/<дата>/`: `run.yaml`, `metrics.jsonl`, `phases.yaml`, `errors.jsonl`, `summary.yaml`, сырые файлы агентов; незавершённый прогон достраивается с агентов при следующем открытии проекта.
- CI гоняет тесты Kafka против Redpanda; релиз прикладывает бинарники CLI рядом с установщиками. Главы руководства «Сьюты», «Агенты и стенды», «Прогон»; руководство администратора описывает агента как службу; «О программе» показывает команду скачивания агента для текущей платформы.

## 0.1.0
Выпущена 2026-10-31. Этап L1 «Каркас и реестр операций» Glafira for Load Testing — настольного инструмента подготовки и сопровождения нагрузочного тестирования.
- Проект НТ — папка в git: манифест `glafira-load.yaml`, сервисы из локальных клонов git с версией из `git describe`, стенды без паролей.
- Импортёры контрактов: OpenAPI 3.0/3.1 и Swagger 2.0, Protobuf, AsyncAPI 2 и 3, Avro и JSON Schema, миграции Flyway и Liquibase, аннотации Spring на Java и Kotlin. Контракты находятся в клоне автоматически.
- Реестр операций со слиянием при повторном разборе (новые, изменённые, удалённые, вернувшиеся; ручные поля сохраняются), снимками разборов и диффом между любыми двумя; ручные операции, в том числе SQL.
- Excel-шаблон нагрузки ПРОМ с защищёнными ID; импорт с предпросмотром заполненных, пустых, неизвестных и ошибочных строк и диффом до записи `load/prod-load.yaml`.
- Профиль нагрузки: коэффициенты с переопределениями по сервисам и операциям, профили из фаз разгона, полки и ступеней, цели и доли, непокрытые операции, график фаз.
- Языки: английский, русский. Встроенное руководство (F1). Политика администратора: `updatesEnabled`, `updateUrl`, `language`.
